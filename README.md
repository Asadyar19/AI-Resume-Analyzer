# AI Resume Analyzer

An AI-powered resume analyzer built with Streamlit and Google's Gemini API.

## Features

- Upload Resume (PDF)
- Extract Resume Text
- Paste Job Description
- AI-powered Resume Analysis
- ATS Score (Coming Soon)
- Skills Match (Coming Soon)
- Missing Skills (Coming Soon)

## Tech Stack

- Python
- Streamlit
- pdfplumber
- Google Gemini API
